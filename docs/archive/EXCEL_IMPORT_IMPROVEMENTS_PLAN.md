## 2. خريطة تدفق البيانات

```
ملف Excel
    ↓
[قراءة وكشف الأعمدة]
    ├─ اسم الضيف (إلزامي)
    ├─ عدد الدعوات (اختياري)
    ├─ نوع التذكرة (اختياري)
    └─ الأعمدة الإضافية ← خزنها في قائمة
    ↓
[عرض معاينة احترافية]
    ├─ جدول بالأعمدة المكتشفة
    ├─ حالة كل عمود (إلزامي/اختياري)
    └─ معاينة البيانات
    ↓
[حفظ البيانات مع metadata]
    {
      invitations: [...],
      availableColumns: ['رقم الهاتف', 'البريد', 'المقعد'],
      columnMapping: {...}
    }
    ↓
[تمرير إلى محرر الدعوات]
    ↓
[اختيار نص ديناميكي]
    ↓
[dropdown: اختر العمود]
    └─ اختيار تلقائي للعمود المناسب
```

## 3. الأعمدة الإلزامية vs الاختيارية

### ✅ إلزامي (يجب أن تكون موجود):
1. **اسم الضيف** - معرّف الشخص
   - الأسماء المقبولة:
     - AR: `اسم الضيف`, `اسم`, `الاسم الكامل`
     - EN: `guest_name`, `name`, `full_name`, `visitor_name`

### ⚠️ اختياري معروف (تحويل تلقائي):
1. **عدد الدعوات**
   - الأسماء: `عدد الدعوات`, `invitation_count`, `count`, `qty`
   - افتراضي: 1
   
2. **نوع التذكرة**
   - الأسماء: `نوع التذكرة`, `ticket_class`, `class`, `type`
   - القيم: `vip`, `v`, `كبار الشخصيات` = VIP | الباقي = normal
   - افتراضي: normal

### 🔲 اختياري إضافي (حفظ كـ custom_fields):
- **الهاتف:** `رقم الهاتف`, `phone`, `tel`, `mobile`
- **البريد:** `البريد`, `email`, `e-mail`
- **المقعد:** `رقم المقعد`, `seat`, `seat_number`
- **الطاولة:** `رقم الطاولة`, `table`, `table_number`
- **الشركة:** `الشركة`, `company`, `organization`
- **الوظيفة:** `الوظيفة`, `title`, `position`, `job`
- **أي عمود إضافي آخر:** محفوظ كـ is
- **المنطقة:** `منطقة`, `zone`, `area`
- **القاعة:** `قاعة`, `hall`, `room`

## 4. رسائل التحذير والأخطاء المحسّنة

### عند رفع الملف:

#### ✅ نجح (Green):
```
✓ تم التحقق من الملف بنجاح
  • 50 صف صحيح
  • أعمدة مكتشفة: 8 (3 إلزامية + 5 إضافية)
  • البيانات جاهزة للاستخدام
```

#### ⚠️ تحذيرات (Yellow):
```
⚠ تم اكتشاف مشاكل بسيطة:
  1. السطر 5: عدد الدعوات فارغ - سيتم استخدام 1
  2. السطر 12: نوع التذكرة غير واضح "V.I.P" - سيتم استخدام VIP
  3. السطر 8-10: لا توجد أسماء للضيوف - سيتم تجاهل هذه الصفوف
```

#### ❌ أخطاء حرجة (Red):
```
✗ لا يمكن استخدام الملف:
  • العمود "اسم الضيف" غير موجود
  • الأعمدة المتاحة في الملف: 
    - guest_name ✓ (هذا هو الاسم)
    - عدد الدعوات ✓
    - نوع التذكرة ✓
  
  ⓘ هل تقصد استخدام "guest_name" كـ "اسم الضيف"؟
```

## 6. الربط مع محرر الدعوات

### قبل (الحالي):
```typescript
{
  type: 'dynamic_text',
  label: 'نص ديناميكي',
  defaults: {
    data_key: '' // يكتب يدويًا: "guest.phone"
  }
}
```

### بعد (الجديد):
```typescript
{
  type: 'dynamic_text',
  label: 'نص ديناميكي',
  availableColumns: [
    { label: 'اسم الضيف', key: 'guest.name', type: 'text' },
    { label: 'رقم الهاتف', key: 'guest.phone', type: 'phone' },
    { label: 'البريد', key: 'guest.email', type: 'email' },
    { label: 'رقم المقعد', key: 'guest.custom_fields.seat', type: 'text' },
    { label: 'الشركة', key: 'guest.custom_fields.company', type: 'text' }
  ],
  selectedColumn: 'guest.phone' // تحديد من dropdown
}
```

- 🔴 أحمر: حقل إلزامي

### 🎨 تحسينات UX:
1. **أيقونات واضحة:**
   - ✓ للأعمدة الصحيحة
   - ⚠ للتنبيهات
   - ✗ للأخطاء الحرجة

2. **جداول بيانات:**
   - header ملون حسب النوع
   - صفوف متناوبة اللون (zebra striping)
   - scroll أفقي للجداول الضخمة

3. **رسائل واضحة:**
   - Arabic-only (بدون خليط)
   - emojis للتوضيح
   - أمثلة عملية

4. **تفاعل:**
   - loading spinner عند المعالجة
   - progress bar للملفات الكبيرة
   - toast notifications للنجاح/الفشل
