🔌 التكامل السريع:
═════════════════════════════════════════════════════════════════════════════

1. استيراج المكون:
   import { ExcelImportDialog } from '../components/ExcelImportDialog'

2. إضافة الـ Button:
   <button onClick={() => setShowExcelImport(true)}>
     📊 استيراج من Excel
   </button>

3. إضافة الـ Dialog:
   {showExcelImport && (
     <ExcelImportDialog {...props} />
   )}

    ↓

  • معاينة البيانات
  • عرض الأخطاء والتحذيرات
    ↓

    ↓
convertToInvitations()
  • تحويل إلى صيغة API
    ↓
Invitations Array (جاهزة للتوليد)
