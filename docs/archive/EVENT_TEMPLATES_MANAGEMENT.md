# 🎨 إدارة قوالب الحفل (Event Templates Management)

## 📋 نظرة عامة

تم إضافة علامة تبويب جديدة في صفحة تفاصيل الحفل تسمح بإدارة القوالب المخصصة:
- ✅ **عرض القوالب** - قائمة بجميع القوالب الخاصة بالحفل
- ✅ **معاينة القالب** - رؤية كيف ستبدو الدعوة مع بيانات اختبارية
- ✅ **حذف القالب** - إزالة قالب من الحفل
- ✅ **تحديث البيانات** - تغيير بيانات الاختبار لمعاينة حالات مختلفة

---

## 🎯 الواجهة الجديدة

### موقع الميزة
- **الصفحة:** تفاصيل الحفل (`/events/{eventId}`)
- **العلامة:** "قوالب الحفل" (الأيقونة: 🎨)

### الأقسام الرئيسية

#### 1. 🎪 عرض القوالب (Templates Grid)
- عرض الخلفية كصورة مصغرة
- اسم القالب
- نوع القالب (مصمم/سريع)
- أبعاد القالب بالبكسل

#### 2. 🔍 الإجراءات السريعة
لكل قالب ثلاثة أزرار:

| الزر | الرمز | الوظيفة |
|------|------|---------|
| **معاينة** | 👁️ | فتح نافذة معاينة تفاعلية |
| **تحميل** | ⬇️ | تحميل الصورة المعاينة كـ PNG |
| **حذف** | 🗑️ | حذف القالب بعد تأكيد |

#### 3. 📸 نافذة المعاينة
تفتح عند النقر على "معاينة":

**اليسار:** صورة الدعوة المعاينة الكاملة
**اليمين:** محرر بيانات الاختبار

---

## 💻 بيانات الاختبار

يمكن تعديل البيانات التالية في نافذة المعاينة:

```typescript
{
  guest_name: string       // اسم الضيف
  event_title: string      // عنوان الحفل
  event_date: string       // التاريخ (YYYY-MM-DD)
  event_time: string       // الوقت (HH:mm)
  event_location: string   // المكان
  seat_number: string      // رقم المقعد
  table_number: string     // رقم الطاولة
}
```

**القيم الافتراضية:**
```javascript
{
  guest_name: "أحمد علي",
  event_title: "حفل تخرج",
  event_date: "2025-06-15",
  event_time: "19:00",
  event_location: "فندق الريتز",
  seat_number: "A12",
  table_number: "5",
}
```

## 🎬 سير العمل

### معاينة قالب

1. انتقل لصفحة تفاصيل الحفل
2. اضغط على علامة "قوالب الحفل" 🎨
3. اختر قالب واضغط زر المعاينة 👁️
4. ستظهر نافذة بالمعاينة الكاملة
5. (اختياري) عدّل البيانات الاختبارية واضغط "تحديث المعاينة"
6. (اختياري) احفظ الصورة بالضغط على "تحميل المعاينة"

### حذف قالب

1. من قائمة القوالب، اختر قالب
2. اضغط الزر الأحمر 🗑️
3. أكد الحذف في رسالة التأكيد
4. سيتم حذف القالب فوراً

**الأنماط:**

#### تحديث `EventDetailsPage.tsx`
```

```

**التغييرات:**
- إضافة `EventTemplatesTab` للاستيراد
- إضافة نوع `'templates'` إلى `Tab` type
- إضافة زر التبويب الجديد
- إضافة لوحة المحتوى للتبويب

### API المستخدمة

#### 1. جلب القوالب
```
GET /api/v1/templates?event_id={eventId}
```

#### 2. معاينة القالب
```
POST /api/v1/templates/{templateId}/preview
Content-Type: application/json

{
  "guest_name": "...",
  "event_title": "...",
  ...
}
```

#### 3. حذف القالب
```
DELETE /api/v1/templates/{templateId}
```

## 🔒 الأمان والصلاحيات

✅ **التحقق من الصلاحيات:**
- يتطلب توثيق (JWT Token)
- يتحقق من صلاحية `templates.view` للمعاينة
- يتحقق من صلاحية `templates.edit` للحذف
- يتحقق من ملكية المستأجر (Tenant)

✅ **حماية البيانات:**
- المعاينة لا تُحفظ في قاعدة البيانات
- لا يمكن حذف قالب بدون تأكيد
- معالجة أخطاء محكمة

## 🎨 الواجهة والتصميم

### الألوان
- **الخلفية:** `var(--color-bg)`
- **النص:** `var(--color-text)`
- **الحد:** `var(--color-border)`
- **الزر الأساسي:** `var(--color-primary)`
- **الخطر (حذف):** `var(--color-danger)`
- **النجاح (تحميل):** `var(--color-success)`

### التأثيرات
- **Hover على البطاقات:** رفع خفيف وظل
- **الانتقال:** 0.3s ease-out
- **الانسحاب:** 0.2s ease-out

### الاستجابة (Responsive)
- **الشاشات الكبيرة:** شبكة 4-5 أعمدة
- **الشاشات المتوسطة:** شبكة 2-3 أعمدة
- **الهاتف المحمول:** عمود واحد
- **نافذة المعاينة:** تتحول إلى عمود واحد على الهاتف

## ⚡ الأداء

- **المعاينة:** استدعاء API لكل معاينة (لا تخزين مؤقت)

- **الصور المصغرة:** يتم تحميلها من Supabase Storage

## 🐛 استكشاف الأخطاء

### لا تظهر القوالب
**الحل:**
- تأكد من أنك قمت بإنشاء قالب للحفل
- تحقق من اتصالك بالإنترنت
- جرب إعادة تحميل الصفحة

### المعاينة لا تظهر
**الحل:**
- تأكد من أن القالب يحتوي على خلفية
- تحقق من وصولك إلى البيانات
- تأكد من أن Supabase Storage يعمل

### الحذف لا يعمل
**الحل:**
- تأكد من أن لديك صلاحية `templates.edit`
- جرب إعادة تحميل الصفحة
- اتصل بالمسؤول إذا استمرت المشكلة
