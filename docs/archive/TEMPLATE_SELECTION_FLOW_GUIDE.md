## 📋 ملخص النظام

نظام احترافي وسلس لإنشاء دعوات مخصصة من خلال:

1. ✅ **اختيار القالب** - اختر من القوالب المتاحة
2. ✅ **تحميل البيانات** - ملف Excel يحتوي على بيانات الضيوف
3. ✅ **استخراج تلقائي** - النظام يكتشف البيانات تلقائياً
4. ✅ **التحقق والتصحيح** - تعديل التعيين يدويًا إذا لزم الأمر
5. ✅ **المعاينة** - رؤية النتائج قبل الإنشاء
6. ✅ **الإنشاء** - توليد الدعوات بنقرة واحدة

## 📊 تنسيق البيانات المطلوب

### ملف Excel المتوقع

```
| اسم الضيف  | التاريخ       | الوقت | رقم المقعد |
|-----------|---------------|------|-----------|
| أحمد محمد  | 2025-06-15   | 19:00| A12       |
| فاطمة علي  | 2025-06-15   | 19:00| A13       |
| محمد سالم  | 2025-06-15   | 19:00| B01       |
```

### الأعمدة المطلوبة

| الحقل | الأسماء المقبولة | الوصف | مثال |
|------|------------------|------|------|
| guest_name | اسم الضيف، name، الاسم | اسم الضيف أو الجهة | أحمد محمد |
| event_date | التاريخ، date، eventdate | التاريخ بصيغة YYYY-MM-DD | 2025-06-15 |
| event_time | الوقت، time، eventtime | الوقت بصيغة HH:MM | 19:00 |
| seat_number | مقعد، seat، رقم المقعد | رقم المقعد أو الموقع | A12 |

## 🐛 استكشاف الأخطاء

### المشكلة: الملف لا يُقرأ

**الحل:**
```
✓ تأكد من صيغة الملف (.xlsx أو .csv)
✓ تأكد من وجود البيانات في الملف
✓ جرب ملف آخر
```

### المشكلة: الأعمدة لا تُكتشف تلقائياً

**الحل:**
```
✓ استخدم الأسماء المشهورة للأعمدة
✓ اختر الأعمدة يدويًا من القائمة
✓ تحقق من أسماء الأعمدة بدون مسافات
```

### المشكلة: البيانات غير كاملة

**الحل:**
```
✓ تأكد من ملء جميع الحقول المطلوبة
✓ تحقق من صيغة التاريخ والوقت
✓ أعد الملف وحاول مرة أخرى
```
